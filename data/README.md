### Agricultural Extension RAG: Smart Retrieval for Farmers Project Datasets
The kaggle competiton mainly provided the dataset used for this project but as a part of chhallenge project 3, we were mandated to create a data card for datasets we would use assuming datasets were not provided.

For the creation of the datcard, we used **IITA (International Institute of Tropical Agriculture) and NATIONAL AGRICULTURAL EXTENSION AND RESEARCH LIAISON SERVICES (NAERLS)** as our sources and these are open source sites that provide agricultural advisory docs to farmers.

The following sources were referenced for use as a source of dataset in our data card documentation:
1. The IITA Books and Chapters journal alongside CGIAR (Consultative Group on International Agricultural Research) which can be accessed [here](https://cgspace.cgiar.org/collections/1df39f25-a92a-4c1e-818b-ed997488cf36/search)
2. The NATIONAL AGRICULTURAL EXTENSION AND RESEARCH LIAISON SERVICES (NAERLS) extension bulletins which can be accessed here [here](https://naerls.gov.ng/bulletins)
